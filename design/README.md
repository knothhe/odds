# odds 设置设计

用浏览器打开 [index.html](index.html)。画布支持平移和缩放；点击画板标题可在实际尺寸下查看独立页面。资源均为本地文件，无需安装依赖或联网。浏览器限制本地资源时，可在仓库根目录运行 `python3 -m http.server 4780 --bind 127.0.0.1 --directory design`，然后打开 `http://127.0.0.1:4780/`。

## 设计与实现

沿用 Onevra 的暖白、炭灰、陶土强调色及现有控件。HTML 表达信息层级、文案、状态与布局意图；图标、字体、控件尺寸和交互以原生 Onevra 为准。默认窗口为 760 × 560，最小为 480 × 420，内容在窗口内滚动；宽度小于 620 时切换为分类选择器和纵向设置行。窗口尺寸与位置交由 MyGo 的 `settings` 状态键保存。

| 画板 | 行为 |
| --- | --- |
| [通用](general.html) | 外观和登录启动直接排列，更新与关于独立分组。登录项不可用时禁用开关并说明原因。版本读取构建元数据。 |
| [Dev 通用](general-dev.html) | 独立 Dev 名称与数据身份，明确说明不参与正式版更新并禁用检查按钮。 |
| [依赖与许可证](about-details.html) | 复用通用页关于分组；复制当前构建版本，打开项目主页，按需展开依赖和许可证原文。窄窗口正文可滚动。 |
| [较新版设置](future-config.html) | 展示文件格式版本和支持版本；保留原件，本次修改不写回，引导升级应用。 |
| [鼠标居中](mouse-center.html) | 快捷键和效果选项分组，录制提示仅在录制时出现；未绑定的快捷键显示「未设置」。窄窗口复用此画板。 |
| [录制中](recording.html) | 提示 Esc 取消、Delete 清除。全局快捷键和菜单快捷键暂停，结束录制、失焦或隐藏窗口后恢复。 |
| [保存失败](save-failed.html) | 本次修改保留在内存。提示不随搜索或分类切换消失；重试期间保留旧错误，成功后清除。 |
| [重试保存](save-retrying.html) | 保留上次错误和原布局，状态文字提示正在保存；成功后清除错误，失败则更新原因。 |
| [退出受阻](quit-blocked.html) | 等待正在进行的保存；保存失败时返回设置，可重试或明确选择「放弃并退出」。重试期间不能重复提交或放弃正在写入的操作。 |
| [配置不可读](read-only.html) | 保留原件，说明修改仅本次有效；不提供可能覆盖原件的重试保存。 |
| [深色](mouse-center-dark.html) | 沿用 Onevra 深色语义颜色与相同布局。 |

软件更新分组展示正式版自动检查说明和手动入口。检查、候选说明、失败、下载进度、跳过与重新启动复用 MyGo 已有原生 updater 设计（`github.com/egoist/mygo/plugins/updater/native`），不建立第二套下载器或更新弹窗；Dev、预览和不具备更新资格的构建有明确原因。

设置保留当前即时生效的交互，不增加应用/取消按钮。退出最多等待 3 秒；成功时保留原生退出或重新启动请求。保存队列只接收不可变快照，串行写入完整配置；较早的完成回调不能改变最新编辑的状态。系统登录项独立读取真实登记结果。关闭或 ⌘W 隐藏设置窗口；菜单栏、第二次启动都可重新打开，显式退出才结束应用。

文案集中在原生实现的 `source/internal/uicopy/copy.go` 和画板的 `copy.js`；画板通过稳定的语义键引用文案。常态页面省去简介、重复标签和常驻教程，录制提示、错误恢复与不可用原因按状态显示。

## 验证与维护

先更新本次涉及的独立画板和 `canvas.js`，再更新原生实现；纯内部改动无需增加画板。检查当前状态、长文本、受影响的深浅外观和最小窗口，确认提示和恢复动作实际可用。

在 `source/` 中运行 `go test ./...` 和 `go tool mygo vet`。需要检查原生控件的离屏画面时，先创建输出目录，再运行 `ODDS_UI_SCREENSHOTS=/绝对路径 go test ./internal/app -run TestSettingsStatesAndLayouts -count=1`。这些图片只用于本地审阅。

用 `go run . --preview` 验证真实原生窗口：配置及窗口状态使用临时目录，不注册全局快捷键，也不更改系统登录项；退出后清理。鼠标移动及高亮预览仍执行真实动作。预览有单独的单实例名称，重复启动会唤醒现有预览。浏览器画板和离屏测试不能证明菜单栏、窗口聚焦、系统快捷键或登录启动已通过实机验收。
